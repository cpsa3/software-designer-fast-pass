## 🎯 考场核心得分策略

1. **上午场（综合知识 75 分）**：
   * 重点抓牢**面向对象(10分)、软工(8分)、数据结构(7分)、计组/系统/数据库/编译(各6分)**，这7个主力盘合计拿下 **49 分基本盘**，直接保送 45 分通过！
2. **下午场（应用技术 75 分）**：
   * **送分铁三角（试题一 DFD + 试题二 数据库 + 试题三 UML）**：通过题干材料消消乐比对，**必须保底 38 ~ 42 分**！
   * **试题六（Java 面向对象）**：坚决选 Java，死抓“抽象/继承/接口语法填空 + 设计模式多态调用”，**稳拿 12 ~ 14 分**！
   * **试题四（算法设计）**：代码写不出绝不死磕，保底拿满“策略判定（2分）+ 复杂度计算（2分）+ 特殊值手工推导（3~4分）”，**稳拿 9 ~ 11 分**！
   * 下午总分轻松突破 **60+ 分**（45 分合格）。
