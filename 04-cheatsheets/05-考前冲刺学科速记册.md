# 第 1 章 计算机组成与存储体系

## 1.1 存储容量与十六进制地址跨度换算

- **【题眼】** 题干给出存储容量（如 `64KB`、`16MB`）求地址空间范围，或给出起始地址与终止地址求芯片数量。
- **【原理】** 十六进制数逢 16 进 1。地址跨度 $L = \text{末地址} - \text{首地址} + 1$。常用 $2^{10}=1024=1\text{K}$ 对应十六进制跨度 `400H`。
- **【考场动作】** 牢记黄金转换表，直接代入进制偏移，无需列长除法：

| 容量规格 | 二进制字节数 | 十六进制跨度 | 典型应用与代入锚点 |
| :--- | :--- | :--- | :--- |
| **1 KB** | $2^{10}\text{ B}$ | `400H` | 基准锚点：$4 \times 16^2 = 1024$ |
| **2 KB** | $2^{11}\text{ B}$ | `800H` | `400H * 2` |
| **4 KB** | $2^{12}\text{ B}$ | `1000H` | 关键锚点：4K 页面后 3 位为偏移 |
| **8 KB** | $2^{13}\text{ B}$ | `2000H` | 芯片扩展常用 |
| **16 KB** | $2^{14}\text{ B}$ | `4000H` | 芯片扩展常用 |
| **32 KB** | $2^{15}\text{ B}$ | `8000H` | 最高位为 8 |
| **64 KB** | $2^{16}\text{ B}$ | `10000H` | 跨度刚好占满 4 位十六进制 |

- **【易错边界】** 末地址减首地址后**必须加 1** 才是实际容量！求芯片片数公式：$\text{芯片数} = (\text{总容量} \times \text{位宽}) / (\text{单片容量} \times \text{单片位宽})$。

## 1.2 寻址空间与地址线引脚推导三大定律

- **【题眼】** “某系统主存容量为 16MB，按字节编址，至少需要多少根地址线？”或“芯片地址引脚数量”。
- **【原理】** 寻址单元数与地址线数量成指数关系：$N = 2^k$。地址引脚只传输地址编码，数据引脚传输数据宽度。
- **【考场动作】** 运用三大黄金推导定律：
  1. **定律一（单位前缀底数拆分）**：
     - $\text{K} \to 2^{10}$（保底 10 根地址线）
     - $\text{M} \to 2^{20}$（保底 20 根地址线）
     - $\text{G} \to 2^{30}$（保底 30 根地址线）
     - 实战：$16\text{MB} = 2^4 \times 2^{20}\text{ B} = 2^{24}\text{ B} \to 24$ 根地址线。
  2. **定律二（十六进制位乘 4 定律）**：
     - 若地址用 $m$ 位十六进制表示，对应二进制地址线为 $4m$ 根。
     - 例如地址范围 `00000H ~ FFFFFH` 共 5 位十六进制，即 $5 \times 4 = 20$ 根地址线，容量 $2^{20} = 1\text{MB}$。
  3. **定律三（编址单位换算铁律）**：
     - **按字节编址**：一个地址对应 1 字节（$8\text{ bit}$）。
     - **按字编址**：一个地址对应一个机器字长（如 $16\text{ bit}$ 或 $32\text{ bit}$）。寻址空间 = 字节总容量 / 字长。
- **【易错边界】** 题目如果写“按字长 16 位编址”，计算地址线前必须将总字节容量除以 2！

## 1.3 存储器存取方式四大金刚辨析

- **【题眼】** 考查 RAM、SAM、DAM、CAM 存取时间与物理介质对应关系。
- **【原理】** 根据内部寻址机理决定存取时间是否与物理位置相关。
- **【考场动作】** 识别四大存储器存取特征对照表：

| 分类名称 | 寻址核心机制 | 存取时间特征 | 典型代表硬件 |
| :--- | :--- | :--- | :--- |
| **随机存储器 (RAM)** | 按地址直接访问单元 | 恒定（与位置无关） | 内存（SRAM / DRAM） |
| **顺序存储器 (SAM)** | 沿物理介质顺序寻道 | 强变（与位置强相关） | 磁带 |
| **直接存储器 (DAM)** | 先直接跳道，后顺序旋转 | 弱变（区域随机+块内顺序） | 机械硬盘、光盘 |
| **相联存储器 (CAM)** | **按内容（数据特征）检索** | 极快（硬件并行并发匹配） | Cache、快表 (TLB) |

- **【易错边界】** 相联存储器绝对不是按地址访问，而是“按内容检索”；看到“按内容寻址”直接秒选 CAM 或 Cache。

## 1.4 SRAM 与 DRAM 核心特性决斗

- **【题眼】** 考查 Cache 与主存介质选型、刷新操作、晶体管结构与集成度。
- **【原理】** SRAM 使用双稳态触发器保存电平，DRAM 利用 MOS 电容电荷存储信息（电荷漏电需动态刷新）。
- **【考场动作】** 从“物理宿命”倒推全部技术指标：

| 比较维度 | SRAM（静态 RAM） | DRAM（动态 RAM） | 考场秒杀口诀 |
| :--- | :--- | :--- | :--- |
| **基本存储单元** | 双稳态触发器（6 管） | 电容 + 1 管 | 静态看触发，动态看电容 |
| **集成度与成本** | 集成度低、价格昂贵 | 集成度高、成本低廉 | 内存要便宜，必须动态做 |
| **存取速度** | 极快（纳秒级） | 较慢（几十纳秒级） | Cache 抢速度，选 SRAM |
| **动态刷新需求** | **不需要刷新** | **必须定期动态刷新** | 电容会漏电，定时刷新保命 |
| **典型系统角色** | CPU 片内 Cache | 计算机主内存 (DDR) | 快且小给 Cache，慢且大给主存 |

- **【易错边界】** 掉电后两者内容**均会丢失**（均属于易失性存储器），不能把“静态”误解为“掉电不丢失”。

## 1.5 定点数表示范围与浮点数加减运算溢出

- **【题眼】** 机器字长 $n$ 位求定点整数表示范围；浮点数对阶、左规、右规中的溢出判断。
- **【原理】** 补码用最高位表示符号，`0` 的表示唯一，负数端多表示一个最小负数 $-2^{n-1}$。浮点数运算 $N = M \times 2^E$，阶码决定范围，尾数决定精度。
- **【考场动作】** 
  1. **数值范围公式（字长 $n$ 位）**：
     - 原码 / 反码：$-(2^{n-1} - 1) \sim +(2^{n-1} - 1)$
     - 补码：$-2^{n-1} \sim +(2^{n-1} - 1)$（8 位字长：$-128 \sim +127$）
  2. **浮点加减运算四步与溢出**：
     - **① 对阶（小阶向大阶看齐）**：小阶码增大，对应尾数右移。**对阶绝对不发生溢出**。
     - **② 尾数加减**：执行对齐后的尾数算术运算。
     - **③ 规格化（溢出高危区）**：
       - **左规**：尾数左移，阶码减小 $\to$ **可能导致阶码下溢**（一般视作机器零，不报错）。
       - **右规**：尾数加减后溢出（如绝对值 $\ge 1$），尾数右移 1 位，阶码加 1 $\to$ **可能导致阶码上溢**（中断报警）。
- **【易错边界】** 对阶时尾数只能**右移**不能左移；右规时阶码增加才会导致真正的上溢硬件中断。

## 1.6 海明码距与检纠错铁律公式

- **【题眼】** “要检测出 $e$ 个错误需最小码距”、“要纠正 $t$ 个错误需最小码距”、“$n$ 位数据需多少位校验位”。
- **【原理】** 码距是任意两个合法码字之间对应二进制位不同的最小位数。纠错能力依赖超球体距离分割。
- **【考场动作】** 记忆三大码距铁律与一个不等式：
  1. **纯检错**：$d \ge e + 1$（如奇偶校验码只能检 1 位错，码距 $d=2$）。
  2. **纯纠错**：$d \ge 2t + 1$（如海明码纠 1 位错，码距至少 $d=3$）。
  3. **检 $e$ 错兼纠 $t$ 错**：$d \ge e + t + 1$（前提 $e > t$）。
  4. **海明校验位计算不等式**：$2^k \ge n + k + 1$（$n$ 为数据位，$k$ 为校验位）。
- **【易错边界】** 考场代入 $2^k \ge n + k + 1$ 时注意包含等号；$n=4$ 时 $k=3$（$2^3=8 \ge 4+3+1$），$n=8$ 时 $k=4$。

## 1.7 DMA 数据传送机制与计算机周期层级

- **【题眼】** “DMA 传送数据占用什么周期”、“指令周期、机器周期、总线周期的耗时层级对比”。
- **【原理】** DMA（直接内存访问）由 DMA 控制器接管总线，在主存与外设之间通过“总线窃取”直接高速交换数据。
- **【考场动作】**
  1. **DMA 周期占用**：每传送一个字（或字节）的数据，**仅占用一个总线周期**（Bus Cycle）。
  2. **周期层级由大到小绝对排序**：
     $$\text{指令周期} > \text{CPU 机器周期（CPU 周期）} > \text{总线周期} \ge \text{时钟周期（节拍脉冲 $T$）}$$
- **【易错边界】** DMA 传送过程**不需要 CPU 执行指令**，CPU 仅在数据块传送开始前进行初始化，在整块数据传送完毕后响应中断。传送单个数据不占用指令周期。

# 第 2 章 操作系统知识体系

## 2.1 页式存储逻辑地址转物理地址

- **【题眼】** 页面大小 $4\text{KB}$，给出十六进制逻辑地址（如 `1D16H`）与页表，求物理地址。
- **【原理】** 逻辑地址由页号与页内偏移量组成。页式系统中，**页内偏移量与物理块内偏移量 100% 相同**。
- **【考场动作】** “高位查表，低位照抄”四步法：
  1. **由页面大小定低位位数**：$4\text{KB} = 2^{12}\text{ B}$，占 12 位二进制，即十六进制后 3 位。
  2. **拆分逻辑地址**：`1D16H` 拆分为：高位页号 `1`，后 3 位偏移量 `D16H`。
  3. **查页表换块号**：查页表，页号 `1` 对应的物理块号假设为 `3`。
  4. **拼接物理地址**：将块号 `3` 与偏移 `D16H` 直接拼接，得 `3D16H`！
- **【易错边界】** 页面大小为 $1\text{KB}$ 时后 10 位二进制（十六进制不规整时需转二进制切分）；淘汰页面时只看在内存的页，访问位为 0 且修改位为 0 优先淘汰。

## 2.2 多级索引文件结构与最大文件长度

- **【题眼】** 13 个地址项（0~9 直接索引、10 一级间接、11 二级间接、12 三级间接），求可表示的最大文件容量。

## 2.4 死锁极值与银行家算法资源判定

- **【题眼】** $m$ 个进程各自最多申请 $w$ 个资源，系统至少需要多少资源才能保证绝不发生死锁。
- **【原理】** 极端最不利原则：每个进程都拿到了 $w - 1$ 个资源，此时系统只要再多出 1 个资源即可打破僵局。
- **【考场动作】**
  - **不死锁临界公式**：$R \ge m \times (w - 1) + 1$。
  - **银行家算法安全性检查**：找当前系统可用向量 `Available` 能够满足其需求向量 `Need` 的进程，分配并回收其已占资源 `Allocation`，直至所有进程进入安全序列。
- **【易错边界】** 题干问的是“可能发生死锁的最大资源数”还是“绝不死锁的最小资源数”：前者是 $m \times (w - 1)$，后者加 1。

## 3.2 CIDR 子网划分与可用主机数秒杀

- **【题眼】** 给定网络号（如 `117.15.32.0/23`），划分为 `/27` 的子网，求可划分的子网数与每个子网可用主机数。
- **【原理】** IPv4 地址 32 位。网络掩码中 `1` 的位数为主机前缀，剩余 `32 - n` 为主机位。
- **【考场动作】** 
  1. **子网数量公式**：$\text{子网数} = 2^{(\text{新掩码位数} - \text{原掩码位数})}$。  
     例如：$/23 \to /27$，差值为 4，可划分 $2^4 = 16$ 个子网。
  2. **可用主机数公式**：$\text{可用主机数} = 2^{(32 - \text{新掩码位数})} - 2$。  
     例如：$/27$ 主机位剩 $32 - 27 = 5$ 位，可用主机数为 $2^5 - 2 = 30$ 台。
- **【易错边界】** 可用主机数必须**减 2**（扣除主机位全 0 的网络地址和全 1 的定向广播地址）。

## 3.3 对称加密与非对称加密算法大比拼

- **【题眼】** 区分对称与非对称算法家族、加解密密钥特性及典型应用场景。
- **【原理】** 对称算法运算速度极快但密钥分发困难；非对称算法安全性高且便于数字签名但速度慢。
- **【考场动作】** 识别两大加密阵营大比拼表：

| 比较维度 | 对称加密算法 | 非对称加密算法 |

## 3.4 数字签名与公钥加密混合工作流

- **【题眼】** “A 向 B 发送机密且防抵赖的邮件，应使用谁的私钥签名、谁的公钥加密？”
- **【原理】** 签名防抵赖（只有发送方自己有私钥）；加密保机密（只有接收方自己能解密）。
- **【考场动作】** 记住终极操作八字口诀：**“签名用己私，加密用他公”**：
  1. **发送方 A 的动作**：
     - 将明文 Hash 得出消息摘要 $H$；
     - 用 **A 的私钥** 对摘要 $H$ 加密生成 **数字签名**；
     - 用 **B 的公钥** 对明文（或对称会话密钥）加密生成密文。
  2. **接收方 B 的动作**：
     - 用 **B 的私钥** 解密还原出明文；
     - 用 **A 的公钥** 解密数字签名验证摘要一致性。
- **【易错边界】** CA 数字证书认证的是**公钥与其持有者身份的合法绑定关系**，验证证书有效性需使用 CA 的公钥。

## 4.2 McCabe 环路复杂度计算三法

- **【题眼】** 给出程序控制流图，计算 McCabe 复杂度 $V(G)$。
- **【原理】** 环路复杂度衡量程序独立线性路径数量，等于图论中的环数加 1。
- **【考场动作】** 掌握三种秒杀计算法（优先用判定节点法）：
  1. **方法 1（判定节点法，考场最快）**：
     $$V(G) = P + 1$$
     其中 $P$ 为流程图中**分支判定节点的数量**（出度 $\ge 2$ 的节点数）。
  2. **方法 2（闭合区域法）**：
     $$V(G) = \text{闭合平面区域数} R + 1$$
  3. **方法 3（边点公式法，标准定义）**：
     $$V(G) = m - n + 2$$
     其中 $m$ 为有向边数，$n$ 为节点总数。
- **【易错边界】** 遇到复合条件判断（如 `if (a > 0 && b > 0)`），必须拆分为两个单条件判定节点计算！

## 4.4 白盒测试逻辑覆盖强度天梯

- **【题眼】** 考查白盒测试 6 种逻辑覆盖标准的覆盖能力强弱比较。
- **【原理】** 覆盖度决定了发现隐藏逻辑错误的概率。
- **【考场动作】** 牢记由弱到强的绝对顺序天梯：
  $$\text{语句覆盖} < \text{判定覆盖（分支覆盖）} < \text{条件覆盖} < \text{判定/条件覆盖} < \text{条件组合覆盖} < \text{路径覆盖}$$
  - **语句覆盖**：每个可执行代码语句至少执行一次（最弱）。
  - **判定覆盖**：每个判定的真/假分支至少经历一次。
  - **条件覆盖**：每个判定中每个逻辑条件的真/假值至少出现一次。
  - **条件组合覆盖**：每个判定中所有条件可能组合至少出现一次。
  - **路径覆盖**：覆盖程序中所有可能的独立执行路径（最强）。
- **【易错边界】** 判定覆盖不能保证条件覆盖，条件覆盖也不能保证判定覆盖；条件组合覆盖能够覆盖前四者，但依然不能覆盖所有路径覆盖。

## 4.6 关键路径法（CPM）与时差计算

- **【题眼】** 给出双代号网络图或前趋任务表，求关键路径工期、某任务总时差（TF）与自由时差（FF）。
- **【原理】** 关键路径是网络图中耗时最长的路径，决定了项目的最短总工期。
- **【考场动作】**
  1. **关键路径识别**：计算所有可能路径长度，**取耗时最大者即为关键路径**；关键路径上的活动时差均为 0。
  2. **总时差 (TF)**：在不影响总工期的前提下，该活动可以推迟的最大时间：
     $$TF = LS - ES = LF - EF$$
  3. **自由时差 (FF)**：在不影响任何紧后活动最早开始时间前提下的推迟时间：
     $$FF = \min(ES_{\text{紧后}}) - EF$$
- **【易错边界】** 关键路径可能不止一条；压缩关键工期时必须同时压缩所有关键路径，否则无法缩短项目总工期。

## 4.7 挣值管理（EVM）核心指标与项目状态

- **【题眼】** 给出计划价值 PV、挣值 EV、实际成本 AC，求进度偏差 SV、成本偏差 CV 及项目当前健康状态。
- **【原理】** EV（挣值）是统一的度量基准，代表“已完工作的预算价值”。
- **【考场动作】** 牢固掌握 EVM 四大核心公式与正负判定法则：

| 评估指标 | 计算公式 | 优良标准状态 | 劣后恶化状态 |
| :--- | :--- | :--- | :--- |
| **进度偏差 (SV)** | $SV = EV - PV$ | $SV > 0$（进度超前） | $SV < 0$（进度延误） |
| **成本偏差 (CV)** | $CV = EV - AC$ | $CV > 0$（成本节约） | $CV < 0$（成本超支） |
| **进度绩效指数 (SPI)** | $SPI = EV / PV$ | $SPI > 1$（超前） | $SPI < 1$（延误） |
| **成本绩效指数 (CPI)** | $CPI = EV / AC$ | $CPI > 1$（节约） | $CPI < 1$（超支） |

- **【易错边界】** 四个公式全是以 **$EV$ 打头**！减去或除以 $PV$ 代表进度，减去或除以 $AC$ 代表成本。大于 0（或大于 1）恒为好状态。

## 5.1 规范化范式判定天梯（1NF ~ BCNF）

- **【题眼】** 给出关系模式 $R(U, F)$，判定其最高满足第几范式。
- **【原理】** 范式级别越高，数据冗余和插入/修改/删除异常越小。
- **【考场动作】** 依次通过四道关卡进行层级判定：
  1. **1NF（第一范式）**：每个属性都是**不可分割的原子值**（无表中表）。
  2. **2NF（第二范式）**：在 1NF 基础上，**消除非主属性对码的部分依赖**（若主键为单属性，则自动满足 2NF）。
  3. **3NF（第三范式）**：在 2NF 基础上，**消除非主属性对码的传递依赖**（非主属性必须直接由候选码决定）。
  4. **BCNF（巴斯-科德范式）**：在 3NF 基础上，**消除主属性对码的部分与传递依赖**（所有函数依赖的左边决定因子都必须包含候选码）。
- **【易错边界】** 若复合主键为 $(A, B)$，存在函数依赖 $A \to C$，则 $C$ 部分依赖于主键，破坏 2NF。

## 5.2 候选码求解闭包算法与属性分类

- **【题眼】** 给出属性集 $U$ 与函数依赖集 $F$，求解关系模式的候选码。
- **【原理】** 候选码能够函数决定整个属性集 $U$，且其任意真子集不能决定 $U$。
- **【考场动作】** “属性分类定位法”：
  1. **只在左边出现的属性 (L 类)**：**必定包含在每一个候选码中**！
  2. **只在右边出现的属性 (R 类)**：**绝对不会出现在任何候选码中**！
  3. **两边都出现的属性 (LR 类)**：可能包含在候选码中，需要尝试组合。
  4. **两边都没出现的属性 (N 类)**：**必定包含在每一个候选码中**！
  5. **算法步骤**：先取 $L \cup N$ 计算属性闭包 $(L \cup N)^+$，若能推出所有属性，则它就是唯一候选码；否则从 $LR$ 类属性中逐个追加计算闭包。
- **【易错边界】** 闭包计算时必须严格使用 Armstrong 公理递归推导，不可漏掉传递关系。

## 5.3 关系代数表达式推导与查询优化准则

- **【题眼】** 将自然语言查询转换为关系代数表达式（选择 $\sigma$、投影 $\pi$、连接 $\Join$）；查询树优化。
- **【原理】** 关系代数优化核心是减小中间临时结果集大小，减少 I/O 次数。
- **【考场动作】**
  - **核心操作符**：
    - $\sigma_{\text{条件}}(R)$：行筛选（水平切分）。
    - $\pi_{\text{属性列表}}(R)$：列筛选（垂直切分）。
    - $R \Join S$：等值且自然合并同名属性连接。
  - **查询优化三大铁律**：
    1. **选择运算尽可能先做（选择下推）**：先 $\sigma$ 过滤掉绝大部分不符合条件的元组。
    2. **投影运算尽可能先做（尽早投影）**：提前消除不参与后续运算的多余列。
    3. **避免产生笛卡尔积**：用内连接或自然连接代替无条件交叉积。
- **【易错边界】** 自然连接会把同名属性合并为一列；而条件等值连接保留两端的同名列。

## 5.4 事务封锁协议级别与两段锁（2PL）

- **【题眼】** 考查一级、二级、三级封锁协议分别防止哪类并发异常；两段锁协议能否保证无死锁。
- **【原理】** 封锁协议是保证事务隔离性（ACID 的 I）与可串行化的关键。
- **【考场动作】**
  - **三大封锁协议对照**：
    - **一级封锁协议**：修改数据时加排他锁（X 锁），事务结束释放 $\to$ **防止“丢失修改”**。
    - **二级封锁协议**：一级基础上，读数据加共享锁（S 锁），**读完立即释放** $\to$ **防止“读脏数据”**。
    - **三级封锁协议**：一级基础上，读数据加共享锁（S 锁），**事务结束时才释放** $\to$ **防止“不可重复读”**。
  - **两段锁协议 (2PL)**：分为加锁阶段（只能加锁不能解锁）和解锁阶段（只能解锁不能加锁）。**2PL 是可串行化调度的充分条件，但不能避免死锁**！
- **【易错边界】** 遵循两段锁协议的事务依然可能产生死锁！

## 6.3 SOLID 面向对象设计原则与反例

- **【题眼】** 考查单一职责、开闭原则、里氏替换、接口隔离与依赖倒置原则的内涵与违背表现。
- **【原理】** 高内聚低耦合的面向对象设计理论基石。
- **【考场动作】** 记忆 SOLID 五大核心定义：
  - **S（单一职责 SRP）**：一个类应该仅有一个引起它变化的原因。
  - **O（开闭原则 OCP，核心基石）**：对扩展开放，对修改关闭。
  - **L（里氏替换 LSP）**：子类必须能够完全替换掉其父类而不破坏原有程序功能。

## 7.1 二叉树数学性质与反向重构铁律

- **【题眼】** 度为 0 与度为 2 节点数推导；已知遍历序列反向重构二叉树。
- **【原理】** 二叉树每个节点的度只能是 0、1 或 2。
- **【考场动作】**
  1. **两大数学性质**：
     - **节点数公式**：叶子节点数（度为 0）恒等于度为 2 的节点数加 1：
       $$n_0 = n_2 + 1$$
     - **空指针域公式**：$n$ 个节点的二叉链表中，空指针域个数恒为 $n + 1$。
  2. **反向构造铁律**：
     - **中序遍历是定海神针**（中序区分左右子树）！
     - 前序序列提供**根节点**（首个元素）；后序序列提供**根节点**（末尾元素）。
     - **【绝对禁区】仅知“前序 + 后序”无法唯一确定一棵二叉树**！
- **【易错边界】** 前序 `ABC` 与后序 `CBA` 可以构造出形态不同的多种二叉树。

## 7.2 哈夫曼树（最优前缀码）构造与 WPL

- **【题眼】** 给出一组权值，求构造的哈夫曼树带权路径长度 (WPL) 或各字符的哈夫曼前缀编码。
- **【原理】** 权值越大的叶子节点离根越近；树中只有度为 0 和度为 2 的节点，无度为 1 的节点。
- **【考场动作】**
  1. **构造步骤**：每次在集合中挑出**权值最小的两个节点**作为左右子树合并，父节点权值为二者之和；放回集合中重复直到只剩一棵树。
  2. **哈夫曼树节点总数**：若有 $n$ 个叶子节点，则总节点数必定为 $2n - 1$（包含 $n - 1$ 个新生成的非叶节点）。
  3. **WPL 计算妙招**：等于所有非叶子节点（合并生成的父节点）权值累加之和！
- **【易错边界】** 哈夫曼编码必须是前缀编码（没有任何一个字符的编码是另一个字符编码的前缀）。

## 7.3 树结构家族（BST / AVL / 红黑树 / B+树）

- **【题眼】** 考查二叉排序树、平衡二叉树、红黑树与 B/B+ 树的特性与检索复杂度。
- **【原理】** 通过树高平衡化控制检索时空效率在 $O(\log n)$ 级别。
- **【考场动作】** 树结构家族对比矩阵：

| 树结构名称 | 核心组织性质 | 考场秒杀特征 |
| :--- | :--- | :--- |
| **二叉排序树 (BST)** | 左子树 $\le$ 根 $\le$ 右子树 | **中序遍历序列必定单调递增**；最坏退化为单链表 $O(n)$ |

## 7.5 排序算法每趟位置确定性与比较次数解耦

- **【题眼】** “一趟排序结束后一定能确定至少一个元素最终位置的是？”、“比较次数与初始排列无关的是？”。
- **【原理】** 局部最值确定性与逆序对消除机制。
- **【考场动作】**
  1. **每趟位置确定性决斗**：
     - **能确定最终位置的（“快堆选冒”）**：快速排序（基准点归位）、堆排序（堆顶最大/小值归位）、简单选择排序（极值归位）、冒泡排序（极值沉底）。
     - **不能确定最终位置的（“插折希归”）**：直接插入排序、折半插入、希尔排序、归并排序。
  2. **比较次数与初始状态完全无关**：
     - **简单选择排序**：无论是否有序，比较次数恒为 $n(n-1)/2$ 次！
     - **基数排序**：按位分配收集，不依赖关键字之间的大小比较。
- **【易错边界】** 简单选择排序虽然比较次数无关，但移动次数有关（初始有序移动 0 次）。

## 7.6 最小生成树算法决斗（Prim vs Kruskal）

- **【题眼】** 考查 Prim 与 Kruskal 算法的核心工作机制、时间复杂度与稠密/稀疏图适用场景。
- **【原理】** 贪心策略构造包含所有 $n$ 个顶点的权值最小无向连通子图（包含 $n-1$ 条边）。
- **【考场动作】** 决斗对照矩阵：

| 比较维度 | Prim 算法（普里姆） | Kruskal 算法（克鲁斯卡尔） |
| :--- | :--- | :--- |
| **出发核心** | **从顶点出发**（切分定理逐步扩充点集） | **从权值最小的边出发**（并查集避圈） |
| **时间复杂度**| $O(V^2)$（使用邻接矩阵） | $O(E \log E)$（按边权堆排序） |
| **适合图类型**| **适合稠密图**（边多的图，耗时只与点有关） | **适合稀疏图**（边少的图，耗时主要由边决定）|

- **【易错边界】** 权重各不相同时，最小生成树形态唯一；存在相同权重边时，最小生成树可能有多棵，但权值总和必定唯一。

## 7.7 常见查找算法性能对比与 ASL

- **【题眼】** 顺序查找、折半查找、分块查找与哈希表（散列表）查找成功/失败的平均查找长度 ASL。
- **【原理】** ASL 为找到目标所经历的关键字比较次数期望值。
- **【考场动作】** 查找算法性能大表：

| 查找算法名称 | 适用数据存储结构 | 查找成功 ASL（平均） | 核心前置条件 |
| :--- | :--- | :--- | :--- |
| **顺序查找** | 顺序表 / 链表 | $(n + 1) / 2$ | 无需有序，效率最低 $O(n)$ |
| **折半查找 (二分)**| **有序的顺序表（数组）** | $\approx \log_2(n + 1) - 1$ | **必须有序且必须能随机存取** |
| **分块查找 (索引)**| 块间有序、块内无序 | $ASL_{\text{块间}} + ASL_{\text{块内}}$ | 建立索引表加速粗筛 |
| **哈希查找 (散列)**| 散列表（地址直接映射） | 冲突解决机制决定（接近 $O(1)$）| 冲突处理法：线性探测、链地址法 |

- **【易错边界】** 单链表即使排好序也不能做折半查找（因为无法在 $O(1)$ 时间内定位中间指针）。

## 7.8 数组与特殊矩阵压缩存储地址推导

- **【题眼】** 二维数组按行/列优先存储的首地址推导；对称矩阵、三对角矩阵压缩下角标映射。
- **【原理】** 将二维/多维连续下标映射为一维内存地址空间。
- **【考场动作】**
  1. **二维数组 $A[m][n]$（下标从 0 开始，每元素占 $L$ 字节）**：
     - **行优先**：$\text{Loc}(A[i][j]) = \text{Base} + (i \times n + j) \times L$
     - **列优先**：$\text{Loc}(A[i][j]) = \text{Base} + (j \times m + i) \times L$
  2. **对称矩阵（$n \times n$ 下三角压缩进一维数组 $B[k]$）**：
     - 当 $i \ge j$ 时：$k = i(i + 1) / 2 + j$（前 $i$ 行元组累加等差数列）。
  3. **考场特值秒杀大法**：不强行背复杂公式，直接代入 $i=0, j=0$ 或 $i=1, j=1$ 校验选项！
- **【易错边界】** 务必看清题目下标是从 0 开始还是从 1 开始！

## 8.4 试题四：五大算法策略与 DP 状态转移

- **【题眼】** 试题四算法策略判定（分治、动态规划、贪心、回溯）；填补 C 语言算法代码核心变量。
- **【原理】** 算法填空本质是对状态转移方程与循环控制条件的映射。
- **【考场动作】**
  1. **五大算法特征题眼速配**：
     - **分治法**：问题拆分、子问题相互独立、递归合并（如归并排序、二分查找）。
     - **动态规划 (DP)**：重叠子问题、最优子结构、**填表格自底向上递推（Memo）**。
     - **贪心法**：每一步做局部最优决策，不可回退（如霍夫曼树、Dijkstra）。
     - **回溯法**：深度优先探索解空间树，不满足条件剪枝回溯（如八皇后、N 皇后）。
  2. **动态规划填空两板斧**：
     - 状态转移方程手算：$0-1$ 背包状态 `dp[i][j] = max(dp[i-1][j], dp[i-1][j-w[i]] + v[i])`。
     - **暂存区比较陷阱**：在堆调整或插入排序下沉中，原变量已被覆盖，**比较时必须与暂存区变量比较**（如 `R[0]` 或 `temp`）！
- **【易错边界】** 循环上下界取等陷阱：区间闭合时必须带等号（如 `r <= N`）。
