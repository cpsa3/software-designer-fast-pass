# 03-case-studies：下午五大题型实战与真题拆解

> 软考中级软件设计师下午科目二（软件设计）满分 75 分，及格线 45 分，是能否拿证的决战盘！

## 🎯 五大题型保底得分战略（保底 63+ 分）

| 题号 | 考核板块 | 推荐分值目标 | 核心破局心法 |
| :---: | :--- | :---: | :--- |
| **试题一** | **结构化分析与数据流图 (DFD)** | **13 ~ 15 分** | 题干说明材料“消消乐比对法”，严抓父子平衡与加工数据守恒 |
| **试题二** | **数据库设计与 E-R 转换** | **13 ~ 15 分** | 两步找漏法：1对多归多端，多对多必须独立建表且联合主键 |
| **试题三** | **UML 建模与面向对象分析** | **12 ~ 14 分** | 区分 BCE 三层类（边界/控制/实体），看准类图菱形与箭头 |
| **试题四** | **C 语言算法设计与分析** | **9 ~ 12 分** | 外围包抄：策略名称(2分) + 复杂度(2分) + 特值手算推导(4分) |
| **试题六** | **Java 面向对象程序设计 (二选一)** | **13 ~ 15 分** | 100% 选 Java！语法填空（extends/implements）+ 模式多态调用 |
