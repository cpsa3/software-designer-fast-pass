# 📚 模块化考点闪卡本 (Q&A Flashcards)

本目录专用于存放从错题衍生或主动记录的**高频核心考点**。
采用 **模块化物理隔离 + 原子化 Q&A 呈现** 的结构化提取练习（Structured Active Recall）模式。

## ⚙️ 记录规范
所有的笔记必须采用以下 Q&A 闪卡格式：

```markdown
## 📌 考点：[考点名称]

> 💡 **Q：[问题描述]**
>
> **A：** [答案描述/对比表格]
> 
> 🎯 **秒杀助记**：[防坑口诀或记忆技巧]
> 🔗 **关联追踪**：[关联错题链接 / 来源]
```

## 🚀 触发规则
1. **主动触发**：直接向 AI 发送指令 `记录考点：[知识点]`，AI 会自动按上述格式整理并归类到对应的模块文件中。
2. **被动建议**：在处理错题时，若 AI 发现极具复用价值的考点，会在回复末尾主动询问，经你同意后再行写入。
