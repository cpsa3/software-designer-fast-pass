## 3. 错题录入标准（四步透析法规范）

每当向本库录入错题时，必须严格执行以下工业级标准：
* **【题目回溯】100% 完整性铁律**：严禁只记录题干，必须**完整还原 A、B、C、D 全部选项内容**，确保后期考前无损二刷。
* **选项诱导逐项剖析**：不仅给出正确选项，必须逐项分析 A/B/C/D 各干扰项设置逻辑与出题人挖坑心理。
* **双向链接母本底座**：每道错题卡片末尾，必须标注指向 `01-fast-pass/` 或 `02-visual-diagrams/` 对应章节的跳转链接。
* **格式零圆圈噪音**：禁用 `①②③④` 符号，采用单层扁平列表。
