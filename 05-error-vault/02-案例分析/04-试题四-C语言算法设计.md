### ⭐ 案例错题 01：2019年5月试题四（N 皇后问题——回溯法递归填空、同列冲突判定与手算摆法漏答） 【🔥重点标星】

> **【真题背景与设问回溯】**
> - **试题背景**：n 皇后问题是指在 $n \times n$ 的棋盘上摆放 n 个皇后，要求任意两个皇后不能在同一行、同一列或同一斜线上。使用数组 `queen[i]` 表示第 $i$ 个皇后的列号（$1 \le i \le n$）。
> - **问题设问**：
>   - 【问题1】（8分，每空2分）根据题干说明，填充 C 代码中的空 (1) ~ (4)。
>   - 【问题2】（3分）根据题干说明和 C 代码，算法采用的设计策略为 (5)。
>   - 【问题3】（4分，每空2分）当 $n=4$ 时，有 (6) 种摆放方式，分别为 (7)。
> - **考生现场作答与估分**：
>   - 问题 1 代码填空：
>     - 空(1)：`queue[i] == j` ❌（拼写错成 queue，且将列号 queen[j] 错写成行号 j）
>     - 空(2)：`1` ✔（得 2 分）
>     - 空(3)：`Place(i)` ❌（传参搞错：行号是 j，列号是 i，应传入当前处理的皇后行号 Place(j)）
>     - 空(4)：`j++` ❌（递归结构误解：递归回溯必须递归调用 Nqueen(j+1)，写 j++ 无法深入下一层）
>     - $\to$ *小计 2 分 / 8 分*（丢 6 分巨款！）。
>   - 问题 2 策略填空：`回溯` ✔（得 3 分）。
>   - 问题 3 摆放方案：写了 `2种`，**但彻底漏答了 (7)“分别为 2413, 3142”！** $\to$ *小计 2 分 / 4 分*（白丢 2 分！）。
>   - *总分诊断*：得 7 分 / 满分 15 分（直接不及格！试题四未能稳拿 8~10 分保底线）。

* **【作答诊断与根因定性】**：
  * 🎯 **标准答案**：
    - **【问题1】**：
      - `(1) queen[i] == queen[j]`
      - `(2) 1`
      - `(3) Place(j)`（或 `Place(j) && j <= n`）
      - `(4) Nqueen(j+1)`
    - **【问题2】**：
      - `(5) 回溯法（或 回溯策略）`
    - **【问题3】**：
      - `(6) 2`（或 2种）
      - `(7) 2413，3142`（或 `(2,4,1,3)，(3,1,4,2)`）
  * 💥 **三大致命翻车根因**：
    1. **【C 语言语法与变量名拼写大忌】**：
       - 把题目定义的数组 `queen` 拼写成队列 `queue`，编译器直接报错未定义符号，判卷 0 分！
       - 对数据结构语义理解颠倒：`queen[i]` 代表“第 $i$ 行皇后的列位置”。检查第 $i$ 个皇后与第 $j$ 个皇后是否**同列冲突**，必须是**两者的列号相等**，即 `queen[i] == queen[j]`！写成 `== j` 属于行与列概念张冠李戴。
    2. **【递归回溯框架模式不敏感（形参 vs 递归步进）】**：
       - `Place` 的签名是 `int Place(int j)`，代表“检验第 $j$ 个皇后（第 $j$ 行）”。考生在 `Nqueen(int j)` 内循环列变量是 `i`，误把 `i` 传进了 `Place`。
       - 摆好第 $j$ 个皇后后，继续摆下一个皇后，是**递归深搜调用 `Nqueen(j+1)`**，写成 `j++` 完全摧毁了递归调用栈。
    3. **【考场审题连带设问又一次漏答】**：
       - 问题 3 包含双空：“有 (6) 种摆放方式，分别为 (7)”。考生只答了 (6)，又一次漏掉了 (7)！白白送出 2 分。

* **【15秒秒杀与破局流水线（试题四递归回溯填空心法）】**：
  * **第一步：外围包抄稳拿 5~7 分保底（策略 + 特值手算）**
    - 题目说明写着“尝试...冲突...回溯到上一个皇后”，策略毫不犹豫写 **回溯法**（直接落袋 3 分！）。
    - 4 皇后手算：4 皇后是经典模型，只有 **2 种** 解法，且关于中心对称：
      - 第一种：第 1 行放第 2 列 $\implies$ 第 2 行只能放第 4 列 $\implies$ 第 3 行放第 1 列 $\implies$ 第 4 行放第 3 列 $\implies$ **2413**！
      - 第二种（镜像对称）：$5-2=3, 5-4=1, 5-1=4, 5-3=2 \implies$ **3142**！
      - 快速写下：`2种，2413 和 3142`（落袋 4 分！）。此时即使代码全不会，外围已经稳拿 7 分！
  * **第二步：代码填空结构化镜像还原（三大探针）**
    - **对称条件探针（空 1）**：
      - 代码：`if( (1) || abs(queen[i] - queen[j]) == (j - i) )`
      - 后面是斜线冲突（列差绝对值 == 行差），前面必然是**同列冲突** $\implies$ 列号相等 $\implies$ `queen[i] == queen[j]`。
    - **函数出口探针（空 2）**：
      - 注释明写“不能返回 0，能返回 1”，冲突全排除后自然返回 `1`。
    - **参数探针（空 3）**：
      - 检查第 $j$ 行当前摆放是否合法 $\implies$ `Place(j)`。
    - **递归调用探针（空 4）**：
      - 外部 main 调 `Nqueen(1)`，当前是 `Nqueen(j)`，摆下一个皇后必然递归调用 `Nqueen(j+1)`！

* **【机考实战防坑口诀与答题规范模板】**：
  * **避坑口诀**：  
    > **变量拼写抠代码，queen 写 queue 判死刑；**  
    > **斜线行差对列差，同列必是 queen 对 queen；**  
    > **递归步进找自调，j 加 1 往深处钻；**  
    > **四皇后是对称俩：二四一三、三一四二！**
  * **答题规范模板**：
    - 算法策略：严格写出标准术语（回溯法 / 动态规划 / 分治法 / 贪心法）。
    - 摆放序列：数字紧凑书写或逗号隔开（`2413, 3142` 或 `(2,4,1,3), (3,1,4,2)`）。

### ⭐ 案例错题 02：2020年11月试题四（希尔排序 Shell Sort——增量折半循环填空、插入逆序判断与跨步长不稳定性辨析） 【🔥重点标星】

> **【真题背景与设问回溯】**
> - **试题背景**：希尔排序算法又称最小增量排序算法，其基本思想是：
>   - 步骤1：构造一个步长序列 $delta_1, delta_2, \dots, delta_k$，其中 $delta_1 = n/2$，后面的每个 $delta$ 是前一个的 $1/2$，$delta_k = 1$；
>   - 步骤2：根据步长序列进行 $k$ 趟排序；
>   - 步骤3：对第 $i$ 趟排序，根据对应的步长 $delta$，将等步长位置元素分组，对同一组内元素在原位置上进行直接插入排序。
>   - C 语言核心代码框架：
>     ```c
>     void shellSort(int data[], int n) {
>         int *delta, k, i, t, dk, j;
>         k = n;
>         delta = (int *) malloc(sizeof(int) * (n / 2));
>         i = 0;
>         do {
>             (1);
>             delta[i++] = k;
>         } while ( (2) );
>         i = 0;
>         while ((dk = delta[i]) > 0) {
>             for (k = delta[i]; k < n; ++k)
>                 if ( (3) ) {
>                     t = data[k];
>                     for (j = k - dk; j >= 0 && t < data[j]; j -= dk) {
>                         data[j + dk] = data[j];
>                     } /*for*/
>                     (4);
>                 } /*if*/
>             ++i;
>         } /*while*/
>     }
>     ```
> - **问题设问与考生实际作答**：
>   - **【问题1】（8分，每空2分）** 填充 C 代码中的空 (1) ~ (4)。
>     - 考生作答：`1、k = k / 2`（✔）、`2、k > 1`（✔）、`3、空（未填）`（❌）、`4、data[j + dk] = t`（✔） $\to$ **6.0 / 8.0 分**。
>   - **【问题2】（4分，每空2分）** 该算法的时间复杂度 (5) $O(n^2)$（小于、等于或大于）。该算法是否稳定 (6)（是或否）。
>     - 考生作答：`(5) 小于`（✔）、`(6) 是`（❌ 错选稳定，希尔排序跨步长分组会导致相对顺序破坏，是不稳定的！） $\to$ **2.0 / 4.0 分**。
>   - **【问题3】（3分）** 对数组 `(15、9、7、8、20、-1、4)` 用希尔排序方法进行排序，经过第一趟排序后得到的数组为 (7)。
>     - 考生作答：`4 9 -1 8 20 7 15`（✔ 手算分组 $dk=3$ 直接插入完全正确！） $\to$ **3.0 / 3.0 分（满分！）**。
>   - *【试题四全卷总分结算】*：实得 **11.0 / 15.0 分**（得分率 **73.3%**，9分及格线稳稳跨过！）。

* **【作答诊断与根因定性】**：
  * 🎯 **官方标准采分点**：
    - **【问题1】代码填空**：
      - `(1) k = k / 2`（或 `k /= 2` 等价形式）
      - `(2) k > 1`
      - `(3) data[k] < data[k - dk]`（或 `data[k] < data[k - delta[i]]`）
      - `(4) data[j + dk] = t`
    - **【问题2】性能与稳定性**：
      - `(5) 小于`（希尔排序复杂度约为 $O(n^{1.3})$，明显小于直接插入的 $O(n^2)$）
      - `(6) 否`（不稳定排序）
    - **【问题3】第一趟手算排序结果**：
      - `(7) (4, 9, -1, 8, 20, 7, 15)`
  * 💥 **两大核心失分根因与深层病理解析**：
    1. **【直接插入逆序判断条件留空（空 3 漏填）】**：
       - 考生准确填出了步长循环折半 `k = k / 2`、退出条件 `k > 1` 以及元素插入落位 `data[j + dk] = t`；
       - 但在 `if((3))` 处留空：直接插入排序的核心在于——只有当当前元素 `data[k]` 比同组前一个元素 `data[k - dk]` 更小（出现逆序）时，才需要执行内部的暂存与元素后移！若已有序，直接跳过当前元素。因此该空为 **`data[k] < data[k - dk]`**。
    2. **【排序稳定性经典认知混淆（误将希尔当稳定）】**：
       - *混淆诱因*：直接插入排序是稳定的，考生容易望文生义，误以为希尔排序作为直接插入的改进版自然也是稳定的。
       - *本质破坏机制*：希尔排序是**跨步长（跨增量 $dk$）分组进行直接插入**的！在某一步长下，两个相同的元素可能被分到不同的组中各自移动，或者跨越中间元素发生跳跃交换，从而彻底破坏原本的先后顺序。
       - *通关铁律*：**四大不稳定排序必须形成秒杀条件反射——“快、选、希、堆（快速排序、简单选择排序、希尔排序、堆排序）”**！

* **【15秒秒杀与破局流水线（希尔排序通关三步法）】**：
  * **第一步：步长数组生成极速定位（秒杀空 1 与空 2）**
    - 题干说明：$delta_1 = n/2$，每个是前一个的 $1/2$，最后为 $1$；
    - `do-while` 循环体：先折半 `(1) k = k / 2`，存入 `delta[i++] = k`，只要 `(2) k > 1` 就继续执行，存入 1 后停止循环！
  * **第二步：组内直接插入两步走（秒杀空 3 与空 4）**
    - 逆序判断：当前比前驱小才搬移 $\implies$ **`data[k] < data[k - dk]`**；
    - 搬移腾出空位：$j$ 向前探测跳出后，目标空位在 $j+dk$ $\implies$ **`data[j + dk] = t`**！
  * **第三步：手算跟踪下标注模法（秒杀问题 3）**
    - 数组长度 $n = 7$，第一趟步长 $delta_1 = 7 / 2 = 3$；
    - 按下标 $\text{mod } 3$ 分为 3 组：
      - 组 0（下标 0, 3, 6）：`15, 8, 4` $\implies$ 排序后为 `4, 8, 15`（填入下标 0, 3, 6）；
      - 组 1（下标 1, 4）：`9, 20` $\implies$ 排序后为 `9, 20`（填入下标 1, 4）；
      - 组 2（下标 2, 5）：`7, -1` $\implies$ 排序后为 `-1, 7`（填入下标 2, 5）；
    - 拼回原序列：`4, 9, -1, 8, 20, 7, 15`！

* **【机考实战防坑口诀与答题规范模板】**：
  * **避坑口诀**：  
    > **希尔步长先折半，大于一做终止判；**  
    > **组内逆序才插入，腾出空位填原值；**  
    > **时间小于方复杂度，四大不稳快选希堆；**  
    > **手算分组看步长，模数同余排各行！**

### ⭐ 案例错题 03：2021年5月试题四（凸多边形最优剖分——区间动态规划同构模型、循环上界闭区间取等与变量重定义避坑） 【🔥重点标星】

> **【真题背景与设问回溯】**
> - **试题背景**：凸多边形最优剖分问题：求将 $N$ 个顶点的凸多边形划分为不相交的三角形集合，且各三角形权重之和最小的剖分方案。
>   - 递推方程：
>     $$m[i][j] = \begin{cases} 0 & i \ge j \\ \min_{i \le k < j} \{ m[i][k] + m[k+1][j] + w(V_{i-1} V_k V_j) \} & i < j \end{cases}$$
>   - $m[i][j]$ 表示点 $V_{i-1} \dots V_j$ 构成多边形的最优剖分权重，$s[i][j]$ 记录分割点 $k$。
> - **设问小题与考生现场实际作答**：
>   - **【问题1】（8分，每空2分）根据说明和 C 代码，填充 C 代码中的空 (1) ~ (4)**：
>     - 考生现场作答：
>       ```text
>       (1) r < N
>       (2) int j=i+r-1;
>       (3) temp < m[i][j]
>       (4) s[i][j] + 1, j
>       ```
>     - *官方标准参考答案对照*：
>       - `(1) r <= N`（或 `r < N + 1`）
>       - `(2) j = i + r - 1`
>       - `(3) temp < m[i][j]`
>       - `(4) s[i][j] + 1, j`
>     - *采分审计*：
>       - 空 (1)：❌ **子问题规模上界截断**。$r$ 代表问题规模（链长），整个凸多边形规模为 $N$，若写 `r < N` 只能计算到规模 $N-1$，目标值 $m[1][N]$ 彻底漏算！扣 2 分；
>       - 空 (2)：⚠️ **算式正确但语法重定义**。算式 $j = i+r-1$ 完全正确，但函数第 15 行已声明 `int i, r, k, j;`，考生画蛇添足加了 `int` 导致局部变量重定义编译风险。严格扣 1 分，宽松判对，实得 1.0 ~ 1.5 分；
>       - 空 (3)：✔ **求最小值判定全对**，得 2.0 分；
>       - 空 (4)：✔ **递归打印右半多边形区间全对**，得 2.0 分。
>     - *考场得分*：**5.0 ~ 6.0 / 8.0 分**。
>   - **【问题2】（7分）策略与复杂度**：
>     - 考生现场作答：
>       ```text
>       (5) 动态规划
>       (6) O(n^3)
>       (7) O(n^2)
>       ```
>     - *官方标准参考答案对照*：
>       - `(5) 动态规划（或动态规划法）`（3分）
>       - `(6) O(n^3)`（2分）
>       - `(7) O(n^2)`（2分）

>   - *【试题四全卷总分结算】*：
