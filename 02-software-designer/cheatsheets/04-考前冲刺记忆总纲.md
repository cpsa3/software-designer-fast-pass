### 1. 得分底线与战役目标
- **及格线恒定 45 分**：上午单选 75 题（满分 75，及格 45）；下午案例 5 道大题（满分 75，及格 45）。
- ⚠️ **双轨铁律**：**单科不过 45，另一科再高成绩也不保留**（不滚动、不互补），严禁偏科！
- **专业英语稳拿策略**：71~75 题看不懂全文没关系，**圈出技术关键词**（deadlock、throughput、schema…），按中文技术常识选，稳拿 3~4 分。
- **心态定位**：不追求 70+ 满分，稳拿 55+ 即可确保安全通关！遇到罕见偏题、怪题果断跳过，把所有精力锁定在 80% 的高频基本盘。

### 2. 机考考场时间分配建议（参考策略）
> [!NOTE]
> 2023 年 11 月机考改革后两科连考（总长通常为 240 分钟）。以下为高频通关经验分配，具体以考场倒计时界面为准：
- **科目一（上午综合知识，75 题）**：建议用时 **85 ~ 95 分钟**。平均 1.1 分钟/题，计算题最多停留 2 分钟。
- **科目二（下午案例分析，5 大题）**：建议用时 **135 ~ 145 分钟**。做题顺序推荐：
  $$\text{试题一 (DFD 25m)} \to \text{试题二 (数据库 25m)} \to \text{试题三 (UML 25m)} \to \text{试题六 (Java 25m)} \to \text{试题四 (算法 30m)} \to \text{终局自检 (10m)}$$

### 3. 遇到难题的“绝对止损铁律”
1. **单题纠结超 90 秒**：立即凭第一直觉选一个选项（绝不留空），打上机考界面的“标记”小旗，立即下一题！
2. **严禁中途反复回查**：顺着往下做，全部做完后再利用最后 10 分钟集中看标记题。
3. **下午案例卡壳**：先做后面小问或换下一道大题；严禁在试题四算法循环手算中耗费超过 15 分钟。

## 1.1 计算机组成与存储体系

- **【流水线周期与执行时间】**
  - **题眼**：流水线各段耗时 $\Delta t_1, \Delta t_2, \dots$ 求 $n$ 条指令总耗时。
  - **结论**：流水线周期 $\Delta t = \max(\Delta t_i)$。理论总耗时 $T = (\Delta t_1 + \dots + \Delta t_k) + (n - 1) \times \Delta t$。
  - **防错**：选项无理论值时选用实践公式：$T = (k + n - 1) \times \Delta t$。
  - **进阶公式**：吞吐率 $TP = n / T$（最大 $TP_{\max} = 1 / \Delta t$）；加速比 $S = \text{串行时间} / \text{流水时间}$。
- **【存储容量跨度速算】**
  - **题眼**：给出十六进制地址范围求容量（如 `80000H ~ BFFFFH`）。
  - **结论**：末地址减首地址加 1：$\text{BFFFF} - \text{80000} + 1 = \text{40000H} = 4 \times 16^4 = 2^2 \times 2^{16} = 2^{18}\text{ B} = 256\text{ KB}$。
  - **防错**：减完必须记得**加 1**；按字编址时需除以字长字节数。
- **【SRAM vs DRAM 判定】**
  - **题眼**：SRAM、DRAM 性能与应用硬件。
  - **结论**：Cache 选 SRAM（触发器、快、贵、不需刷新）；主存选 DRAM（电容、慢、便宜、**必须定期动态刷新**）。
  - **防错**：两者断电后数据均丢失，均为易失性。
- **【浮点数加减运算与溢出】**
  - **题眼**：对阶规则与阶码上溢/下溢判定。
  - **结论**：**小阶向大阶看齐**（小阶码增加，尾数右移，绝对不溢出）；**左规可能下溢**，**右规可能上溢**（中断报警）。
  - **防错**：对阶时尾数只能右移不能左移。
- **【DMA 数据传送周期】**
  - **题眼**：DMA 传送每个数据占用什么周期。
  - **结论**：每传送一个字/字节，**仅占用一个总线周期**（总线窃取）。
  - **防错**：DMA 传送单个数据**不占用指令周期**，完全架空 CPU。
- **【海明码距与检纠错公式】**
  - **题眼**：检错码距、纠错码距、校验位数量。
  - **结论**：检 $e$ 错 $d \ge e + 1$；纠 $t$ 错 $d \ge 2t + 1$；校验位不等式 $2^k \ge n + k + 1$。
  - **防错**：海明码默认纠 1 位错，码距至少为 3。详见 [学科册 1.6](05-考前冲刺学科速记册.md#16-海明码距与检纠错铁律公式)。

## 1.2 操作系统核心决策

- **【页式存储地址转换】**
  - **题眼**：页面大小 4KB，逻辑地址十六进制求物理地址。
  - **结论**：“4K 页面看后三，高位查表换块号，后三偏移照样抄”。
  - **防错**：页面大小 4KB 对应十六进制低 3 位；淘汰页面优先选“在内存、未访问、未修改（0,0）”。
- **【PV 操作前趋图】**
  - **题眼**：前趋图各节点执行前后的 P、V 信号量填空。
  - **结论**：**入度执行 P 操作，出度执行 V 操作**。
  - **防错**：每条有向边对应一个唯一信号量，初值通常为 0。
- **【不死锁临界资源数】**
  - **题眼**：$m$ 个进程各自申请 $w$ 个资源，系统不发生死锁的最小资源数。
  - **结论**：$R \ge m \times (w - 1) + 1$。
  - **防错**：题目问“可能发生死锁的最大值”时不要加 1。详见 [学科册 2.4](05-考前冲刺学科速记册.md#24-死锁极值与银行家算法资源判定)。
- **【位示图法字号位号速算】**
  - **题眼**：字长 $W$ 位系统，求物理块号对应的字号与位号。
  - **结论**：字号 $= \lfloor \text{块号} / W \rfloor$，位号 $= \text{块号} \bmod W$。
  - **防错**：🚨 问“第几个字”（从 1 起算）必须 **加 1**——先确认编号基准再动笔！详见 [学科册 2.5](05-考前冲刺学科速记册.md#25-位示图法bitmap空间分配与差-1-陷阱)。

## 1.3 语言与编译原理

- **【编译阶段与错误定位】**
  - **题眼**：非法字符、括号不匹配、类型不匹配在哪个阶段检出。
  - **结论**：
    - 非法字符 $\to$ 词法分析；
    - 括号不配对/缺分号 $\to$ 语法分析；
    - 类型不兼容/未声明使用 $\to$ 静态语义分析。
  - **防错**：**死循环、除零、越界属于动态运行期错误**，编译器在编译阶段完全无法查出！
- **【参数传递传值 vs 传址】**
  - **题眼**：形参改变是否同步改变实参。
  - **结论**：值调用（传值）传副本，实参绝不改变；引用调用（传址）传别名，实参同步改变。

## 1.4 软件工程与项目管理

- **【McCabe 环路复杂度】**
  - **题眼**：控制流图计算环路复杂度 $V(G)$。
  - **结论**：$$V(G) = P + 1$$（$P$ 为出度 $\ge 2$ 的判定节点数）。
  - **防错**：遇到复合判断（`a > 0 && b > 0`）必须拆为 2 个判定节点计算。
- **【白盒测试覆盖天梯】**
  - **题眼**：发现错误能力最强/最弱的逻辑覆盖标准。
  - **结论**：语句（最弱）$<$ 判定 $<$ 条件 $<$ 判定/条件 $<$ 条件组合 $<$ 路径（最强）。
- **【过程模型选型字典】**
  - **题眼**：需求明确选瀑布；需求模糊选原型；**风险驱动选螺旋**；**面向对象迭代无缝选喷泉**。
- **【挣值管理 EVM 公式】**
  - **题眼**：求进度偏差 SV、成本偏差 CV。
  - **结论**：全以 $EV$ 打头！$SV = EV - PV$；$CV = EV - AC$。大于 0（或指数大于 1）恒为好状态。详见 [学科册 4.7](05-考前冲刺学科速记册.md#47-挣值管理evm核心指标与项目状态)。

## 1.5 数据库系统与规范化

- **【规范化范式层级关卡】**
  - **题眼**：判定关系最高满足第几范式。
  - **结论**：
    - 1NF：属性原子不可分；
    - 2NF：消除非主属性部分依赖（单属性主键自动满足 2NF）；
    - 3NF：消除非主属性传递依赖；
    - BCNF：消除主属性对码的部分与传递依赖（左边决定因子全含候选码）。
- **【候选码求解闭包】**
  - **题眼**：给出函数依赖集求候选码。
  - **结论**：**只在左边出现的属性 (L) 必在码中**；**只在右边出现的属性 (R) 绝不在码中**。
- **【关系代数查询优化】**
  - **结论**：**选择下推优先做**，**尽早做投影**，避免笛卡尔积。
- **【事务并发封锁协议】**
  - **结论**：一级防丢失修改（写加 X 锁）；二级防读脏（读加 S 锁用完即放）；三级防不可重复读（S 锁事务结束放）。两段锁 (2PL) 保证可串行化，**但不能防死锁**。

## 1.6 网络互联与信息安全

- **【OSI 七层、PDU 与设备映射】**
  - **结论**：
    - 应用/表示/会话层 $\to$ 报文 (Data) $\to$ 应用网关；
    - 传输层 $\to$ 报文段 (Segment) $\to$ TCP/UDP；
    - 网络层 $\to$ 分组/包 (Packet) $\to$ **路由器**；
    - 数据链路层 $\to$ 帧 (Frame) $\to$ **网桥/二层交换机**；
    - 物理层 $\to$ 比特流 (Bit) $\to$ **集线器/中继器**。
- **【CIDR 子网与主机数速算】**
  - **结论**：子网数 $= 2^{\Delta \text{掩码}}$；可用主机数 $= 2^{(32 - \text{新掩码})} - 2$。主机数必须**减 2**！
- **【加解密与数字签名原则】**
  - **结论**：**“签名用己私，加密用他公”**。公钥加密私钥解密保机密；私钥签名公钥验签防抵赖。
  - **算法分类**：DES/AES/RC4 为对称（快）；RSA/ECC 为非对称（慢）；MD5/SHA 为摘要（不可逆）。

## 1.7 数据结构与算法基础

- **【二叉树数学性质】**
  - **结论**：$n_0 = n_2 + 1$（叶子节点数恒等于双分支节点数加 1）；$n$ 个节点的链表空指针数为 $n + 1$。
- **【二叉树遍历重构】**
  - **结论**：**中序遍历为定海神针**，前序定首根，后序定尾根；**前序 + 后序绝对无法唯一确定二叉树**！
- **【排序算法每趟位置确定性】**
  - **结论**：
    - 每趟必有一元素落位最终位置（“快堆选冒”）：**快速排序、堆排序、简单选择、冒泡排序**；
    - 每趟不能确定最终位置（“插折希归”）：直接插入、折半插入、希尔、归并排序。
- **【最小生成树算法选型】**
  - **结论**：Prim（顶点出发，时间 $O(V^2)$，适合**稠密图**）；Kruskal（边出发，时间 $O(E \log E)$，适合**稀疏图**）。详见 [学科册 7.6](05-考前冲刺学科速记册.md#76-最小生成树算法决斗prim-vs-kruskal)。

## 2.1 试题一（DFD 数据流图）：四步得分流水线

- **【审题动作】** 快速通读题干与顶层图，标记外部实体数量与主要业务目标。
- **【动作卡 1：数据存储命名】**
  - **红线 1**：**说明原文字面抄，说明无表不加表**！题干写“基础信息”，绝不能写成“基础信息表”。
  - **红线 2**：说明写“用户信息表”才老实带上“表”；核心定语不可删（“订餐订单”不能写“订单”）。

# 3. 跨模块高频易混点横向穿透（对比大表）

## 3.1 内聚与耦合天梯对照

- **内聚天梯（由弱到强，内聚越高越好）**：
  $$\text{偶然内聚} < \text{逻辑内聚} < \text{时间内聚} < \text{过程内聚} < \text{通信内聚} < \text{顺序内聚} < \text{功能内聚（最高）}$$
- **耦合天梯（由弱到强，耦合越低越好）**：
  $$\text{非直接耦合（最弱）} < \text{数据耦合} < \text{标记耦合} < \text{控制耦合} < \text{外部耦合} < \text{公共耦合} < \text{内容耦合（最差）}$$
- **判定口诀**：传基本数据是数据耦合；传整块结构体是标记耦合；传控制标志位是控制耦合；**共享外部资源（如 I/O 设备、通信协议）是外部耦合**；共享全局变量是公共耦合；直接访问私有代码是内容耦合。
- **实例题眼**：`read_from_file()` 两个模块都调用 → **外部耦合**（共享 I/O 资源）；`print_to_printer()` 两个模块都调用 → **外部耦合**。

# 4. 考前 15 分钟与交卷前终极检查清单

## 4.1 考前 15 分钟闭目必背公式清单

1. **流水线周期与总执行时间**：$\Delta t = \max(\Delta t_i)$，$T = \sum \Delta t_i + (n - 1) \times \Delta t$；吞吐率 $TP_{\max} = 1 / \Delta t$。
2. **海明校验位不等式与纠错码距**：$2^k \ge n + k + 1$；纠 1 错码距 $d \ge 3$。
3. **不死锁临界资源数**：$R \ge m \times (w - 1) + 1$。
4. **二叉树叶子与双分支节点**：$n_0 = n_2 + 1$；$n$ 节点链表空指针数 $= n + 1$。
5. **McCabe 环路复杂度**：$V(G) = P + 1$（$P$ 为判定节点数）。
6. **CIDR 可用主机数**：$\text{可用主机数} = 2^{(32 - \text{掩码})} - 2$。
7. **挣值管理双偏差**：$SV = EV - PV$；$CV = EV - AC$。
8. **存储容量十六进制跨度**：1K = `400H`；4K = `1000H`；64K = `10000H`。
