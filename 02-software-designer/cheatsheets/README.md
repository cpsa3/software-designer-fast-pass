## 🧭 复习使用顺序与同源维护约定

### 1. 黄金复习路径（先学科册，后总纲）
1. **第一阶段（考前 3 ~ 7 天）**：全面通读 [《05-考前冲刺学科速记册》](05-考前冲刺学科速记册.md)，系统穿透 8 大学科的原理推导、对比矩阵与易错边界，夯实底层逻辑。
2. **第二阶段（考前 1 ~ 2 天及进考场前）**：极限切换至 [《04-考前冲刺记忆总纲》](04-考前冲刺记忆总纲.md)，脱离长篇解释，纯粹训练“看见题眼立即反应动作”，强记终局自检法与保命公式。

### 2. 双文档同源维护规范
- **单一事实来源 (SSOT)**：同一考点、公式与结论在两份文档中必须严格一致，总纲仅对学科册做精简压缩与动作化萃取，不得产生结论冲突。
- **素材溯源与存储**：输入素材（如冲刺截图）仅作为整理来源，正文严禁直接嵌入大图，通过 HTML 注释（如 `<!-- 来源：截图 XXX；核验：... -->`）实现无感追溯；原始截图目录不纳入正式文档。
- **动态考试规则隔离**：考试时长、题型比例、机考操作等可能变动的考务规则，必须以官方最新通报或准考证为准，未经官方核验的信息仅标注为参考建议，不得固化为技术事实。
