## 🚫 为什么彻底清除了其余 50+ 份杂乱文件？

1. **剔除老旧清华第 1 版与机构自编第 4 版**：2009 年老考纲充斥 CORBA、DCOM 等废弃技术；机构自编版与官方第二版重叠且臃肿，保留多本只会制造“该看哪本”的心理内耗；
2. **剔除 2023/2024 年散乱 100 条与过期押题**：押题时效已过，且散落的短篇 PDF 信息碎片化严重；
3. **剔除 30+ 篇外部老旧论文 Word 散片**：
   - 外部网络范文多为十年前老系统（大多涉及过时架构），机考查重系统极易判套作低分；
   - 论文备考的核心不是“读 30 篇别人写的文章”，而是**立足自己在 [05-thesis-vault/](../../03-system-architect/05-thesis-vault/) 中打造的唯一《万能项目母本》**，以不变应万变！
