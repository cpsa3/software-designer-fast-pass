## 💡 资料归档与第一性原理食用指南

1. **查漏补缺，不做仓鼠**：
   * 本目录仅用于存放原始参考书和外部讲义，**严禁陷入“把资料下载完等于学会了”的心理陷阱**；
   * 主力刷题与核心笔记依然在根目录的 `quiz-architect.html` 与 `03-system-architect/` 对应 Markdown 中。
2. **论文外源参考的使用方法**：
   * `03-论文外源参考/` 中存放的论文仅作为“技术词汇与架构图灵感来源”；
   * 严禁直接照抄外部现成范文（阅卷系统与查重会判定套作），应将外部论据提炼后融入你自己在 `03-system-architect/05-thesis-vault/` 中打磨的**个人真实业务万能母本**。
3. **平板/离线阅读**：
   * 如需拷贝至 iPad、微信读书或 Kindle 离线翻阅，直接拷贝整个 `materials/` 文件夹即可。
